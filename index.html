How to

Use a template

  1. Scroll the gallery. Every template clip autoplays muted, looped, and inline (including iPhone). These are the real driving videos from the catalog.
  2. Tap a motion to select it. Nothing is generated yet.
  3. Upload a still of the person who should become the character (JPG or PNG, face or full body). The upload stays locked until a template is selected.
  4. Optionally edit the prompt.
  5. Tap Generate. Wan Animate runs on Runpod using your still and the selected motion. The first Generate may take several minutes while the worker starts (it scales to zero when idle). Leave this tab open. You get a short clip of that person in the template motion.
  6. Optionally Extend once or Auto-extend for a longer clip. Extend uses the Hugging Face Space and cannot continue a clip that Generate made on Runpod.
  7. If Generate says Runpod is out of credits, add credits on the Runpod account and try once. If the worker was idle, wait for it to finish starting instead of tapping Generate again.

Create a new template

A template is one short real person-motion driving clip. This is not a LoRA trainer and does not take a folder of training videos.

  1. Length: about 3–5 seconds. Today’s clips (demo-wave, demo-dance, demo-victory, demo-walk) are 4.0s. Generate sends that public motion clip to Runpod with your still.
  2. Picture: one person, motion that reads clearly (wave, dance, walk, gesture). MP4, H.264. Prefer a stable camera and a readable face or full body.
  3. Id: lowercase, hyphens, stable once published, for example demo-wave. Do not reuse an existing id unless you mean to replace that motion.
  4. Add it to the dataset Simzy/wan22-template-clips on branch main:
    • File path: templates/<id>.mp4
    • Append one object to templates/catalog.json (a JSON array) with id, title, description, video_path (templates/<id>.mp4), duration_s, tags, category (greeting, dance, pose, locomotion, …), thumbnail (null or a path), and source (credit and license).
  5. Keep the existing ids unless you intend to change those motions. Add a new id beside them.
  6. Commit to the dataset. This page and the Space both read that catalog. A catalog-only addition does not need an app redeploy.
  7. Tap Refresh so the new clip shows up in the gallery.

Clips already in the dataset use the Mixkit Stock Video Free License, except demo-victory, which is from Wan-Video/Wan-Animate-2 examples/demo1/template.mp4 (Apache-2.0).
